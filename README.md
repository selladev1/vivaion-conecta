# Vivaion Conecta

Diretório de profissionais da saúde, com busca híbrida de baixo consumo.

## Estado inicial

Repositório inicializado para desenvolvimento. A primeira versão será entregue em uma branch com revisão e testes. Nenhum ambiente de produção foi alterado.

Dados de demonstração serão inteiramente sintéticos, sem CPFs, registros profissionais ou contatos reais. O ambiente de testes não deve receber dados pessoais ou queixas reais de saúde.
